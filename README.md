# hackathon-grupo36 — Camaleón

Extensión de navegador que usa el Claude de cada persona para adaptar la interfaz de cualquier sitio web a su gusto,
y un servidor central que aprende de toda la comunidad para recomendar interfaces entre usuarios.

Demo de la hackatón (tema "multiplayer"): YouTube en Firefox.
