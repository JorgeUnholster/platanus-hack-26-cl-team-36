# hackathon-grupo36

Extensión de navegador que usa el Claude de cada persona para adaptar la interfaz de cualquier página web a su gusto,
y un servidor central que aprende de toda la comunidad para recomendar interfaces entre usuarios.

Proyecto de la hackatón (tema "multiplayer"). El nombre del producto está por definir.
